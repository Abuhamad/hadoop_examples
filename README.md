# hadoop_examples

This repo collects small Hadoop MapReduce examples for learning and demos. Each folder focuses on a specific pattern and includes a README with build/run steps.

## Included examples

- [WordCount](WordCount/README.md): Word count implementations and a basic
	compile/run walkthrough.
- [TopN](TopN/README.md): Top-N word frequency jobs, including a naive all-in-
	memory approach and more scalable variants.
- [WeatherAnalysis](WeatherAnalysis/ReadMe.md): Monthly temperature statistics
	and sorting results by mean temperature.

### Sample input data is in [Assets](Assets/)!
